# StillPoets 独立多端应用 PRD（规划草案）

## 一、项目背景与初衷

StillPoets 源于前身项目 AnyQuote（运行在 iOS Scripting App 内的轻量级小组件与单页详情脚本）。随着诗集格式解析、内容库随机抽取和多来源切换能力的逐步完善，用户对“**诗歌沉浸式阅读、个性化精选句子收藏、以及跨设备无缝体验**”提出了更高要求。

本项目旨在将原本依附于 Scripting 脚本宿主的能力彻底独立出来，演进为名为 **StillPoets** 的跨多端专属应用（独立 App + Web）。

> **核心设计理念**：**让你记住，自己依然是诗人（Still a Poet）。** 读诗不该是一件需要仪式感、正襟危坐才能开始的重事——通过桌面小组件把诗句轻轻放到日常视线里，让用户在每次抬眼解锁、碎片停顿的瞬间，都能毫无阻力地开启一首诗。

* **核心初衷**：为用户提供一个纯粹、优美且完全私有的“诗集阅读与心仪句子管理/渲染”空间，以极低门槛陪伴并提醒用户在碎片时间里重新读诗。
* **核心基调**：轻量、优雅、数据私有（BYOD）、内外联动（小组件轻量相遇，点入即展开整诗）。

## 二、多端形态与支持范围

未来脱离 Scripting 环境后，应用采用统一的设计语言分阶段推进：**第一期聚焦 iOS / Android 移动双端；后续阶段可考虑扩展 Web / PWA 端；桌面端（Windows / macOS）明确不做。**

| 平台 | 规划阶段 | 形态定位 | 关键能力 |
| --- | --- | --- | --- |
| **iOS / iPadOS** | 第一期（主力） | 移动主端 | 原生桌面小组件（多尺寸）、锁屏小组件、离线阅读、手势翻页 |
| **Android** | 第一期（主力） | 移动主端 | 桌面微件（App Widget）、Material/沉浸排版、离线存储 |
| **Web 端（PWA）** | 后续可选 | 轻量接入端 | 随时随地跨设备浏览与管理诗集及句子，支持 PWA 安装 |

### 2.1 V1.0 与 V1.1 范围收敛（开发基线）

* **V1.0（第一期可日常自用版）**：
  * 平台与布局：iOS（iPhone）+ Android（**优先做好平板大屏/双栏自适应布局**）。
  * 核心功能：EPUB 导入（含原文件同步）+ 入口 B（独立句子库导入与出处筛选）+ WebDAV 元数据同步与诗集按需下载 + 现代诗横排阅读器（单诗内上下滑动、左右滑切诗、**自定义字体**）+ 诗集/诗篇 ❤️ 收藏 + 基础桌面小组件（iOS 小/中号 + Android 中号，3 套主题，支持手动选句设为本诗金句）。
* **V1.1（第二期增强）**：
  * 单诗微批注与诗集长书评。
  * 数据统计（完读墙、按诗篇热力图、时段占比、诗人作者云）。
  * 高清分享卡片导出引擎（单句/整诗/合辑/年度报告）。
  * 古诗词竖排阅读模式、iOS 锁屏/大号小组件与更多主题。
* **后续可选**：Web / PWA 轻量端（桌面端 Windows / macOS 明确不做）。

## 三、版权规避与私有化存储策略（WebDAV）

为彻底避免诗歌、图书版权争议与中心化服务器存储成本，平台确立**“应用只做阅读渲染与本地管理，内容数据用户自带”**的原则：

1. **私有存储接入**
   * 用户提供自己的 WebDAV 服务（如坚果云、Nextcloud、群晖 NAS、InfiniCLOUD 等）。
   * 用户将下载的诗集文件（如 EPUB、结构化 JSON、导出文本）存入个人 WebDAV 专属目录中。
2. **应用端职责**
   * 应用只持有 WebDAV 访问授权，负责远程目录扫描、增量拉取、本地数据库缓存（如 SQLite / IndexedDB）。
   * 本地提供格式转换与解析引擎，负责优雅排版、诗行诗节对齐与多主题渲染。
   * 服务端无需搭建中心化版权内容库，天然免疫版权纠纷。

## 四、双入口数据组织模型

为了防止不同结构的数据互相污染，在数据上传和导入阶段物理区分两个独立入口：

```
                    ┌─────────────────────────┐
                    │      用户导入入口        │
                    └───────────┬─────────────┘
                                │
        ┌───────────────────────┴───────────────────────┐
        ▼                                               ▼
┌───────────────────────────┐               ┌───────────────────────────┐
│     入口 A：诗集体系       │               │   入口 B：独立句子/摘录   │
│ (完整篇章 / 诗行 / 诗节)   │               │ (纯段落 / Reeden / 读书卡)│
└─────────────┬─────────────┘               └─────────────┬─────────────┘
              │                                           │
   支持整诗阅读、诗节展开                        仅记录文本、来源、原书
   支持写单诗点评、诗集书评                      支持按原书/作者筛选
```

### 4.1 入口 A：诗集导入（结构化整本）
* **支持格式**：EPUB 诗集、多篇目 JSON、带目录标记的 Markdown。
* **数据特征**：具有层级结构（书名 -> 篇名 -> 诗节 -> 诗行），支持从片段追溯整首诗。
* **用途**：提供给 App 内做全本阅读、目录跳转，以及为桌面小组件提供“外看诗选、内阅全诗”的联动能力。

### 4.2 入口 B：独立句子 / 摘录导入（散装段落）
* **支持格式**：Reeden 导出段落、微信读书导出文本、单行摘录 JSON/TXT。
* **数据特征**：没有整诗上下文，仅为单条优美短句、金句或感悟段落，包含：正文内容、作者（可选）、原书出处（可选）。
* **用途**：专供每日金句轮播与单句卡片分享。

## 五、精细化收藏夹体系

收藏夹打破传统“单一列表”模式，提供明确的层级和筛选维度：

### 5.1 用户级别收藏夹（诗集级）
* 用户可以直接管理多本诗集（增、删、改、查、标星收藏到某一诗集组中）。
* 对诗集组进行管理，排序和解散。（默认有一个全部诗集组）

### 5.2 诗集内“精选集”收藏夹（诗篇级 ❤️）
* **交互形式**：用户在阅读某本诗集时，遇到特别心动的篇目，可点击**小红心 ❤️**。
* **作用**：该首诗被自动加入“当前诗集的精选池”。
* **价值**：
  * 用户可以只浏览这部诗集的私家精华列表。
  * 桌面小组件可以配置为“仅在该诗集的精选池中随机抽选”，大幅提升小组件展示质量。

### 5.3 独立句子级收藏（句子级）
* 收藏粒度严格限定为**单条句子**，不上升为诗集维度。
* 支持根据“源于的书”（来源出处）进行聚合筛选与检索。
* 适合存放琐碎但击中人心的散句与札记。

## 六、内外联动的小组件（Widget）机制

小组件是 StillPoets 最核心的日常入口，主打“微打扰、高品味、深沉浸”：

```
┌─────────────────────────────────┐
│           桌面小组件            │
│  “面朝大海，春暖花开”           │ ──(点击小组件)──┐
│             —— 海子             │                 │
└─────────────────────────────────┘                 │
                                                    ▼
                             ┌─────────────────────────────────┐
                             │       进入 App：整首诗详情      │
                             │ 从明天起，做一个幸福的人        │
                             │ 喂马、劈柴，周游世界            │
                             │ 从明天起，关心粮食和蔬菜        │
                             │ 我有一所房子，面朝大海，春暖花开│
                             │ ......                          │
                             │ 【 ❤️ 加入精选 】 【 ✍️ 诗评 】  │
                             └─────────────────────────────────┘
```

1. **桌面外侧展示**：
   * 默认只展示诗歌中精选的一节、名句或短小片段（避免长诗在小组件内字号过小或排版溢出）。
   * 尺寸支持：小尺寸（单句精粹）、中尺寸（短诗/诗节 + 出处）、大尺寸（双语或长诗节）。
   * 随机从用户的诗集中选择，有如下随机方式（全局随机-所有的诗集中随机，固定某个诗集随机/顺序，在该诗集的精选池中随机抽选）
2. **点击深层联动（Deeplink）**：
   * 用户在桌面上点击该句子，直接呼起独立 App 并跳转至对应诗歌的**完整全文阅读界面**。
   * 短暂高亮桌面小组件刚刚节选的句子。
   * 解决传统一言小组件“看到半句想看全诗却无从查找”的痛点。
3. **小组件多样化主题**：
   * 支持水墨宣纸、暗黑极简、牛皮纸复古、莫兰迪色系、透明磨砂玻璃等预设主题。
   * 支持自定义字体（宋体、楷体、衬线体等），确保与手机桌面壁纸风格完美契合。

## 七、阅读、点评与创作空间

App 内部不仅是“看句子”，更是专注的“诗集阅读器”：

1. **单诗点评（微批注）**：
   * 用户在阅读某一首具体的诗时，可随时记录对该诗的灵感、情绪、赏析。
2. **诗集整体书评（长书评）**：
   * 针对整部诗集撰写长篇读后感或阶段性评价。
3. **沉浸式排版**：
   * 针对诗歌特有的排版特点（居中、左对齐、诗行缩进、诗节间距）专门设计阅读器排版引擎，支持**自定义字体导入与切换**（V1.0 必做）。
   * 交互采用**单首诗内上下滑动阅读 + 左滑右滑切换下一首/上一首诗**；同时适配 Android 平板大屏（如目录+正文双栏或居中黄金阅读列宽）。
   * 竖排阅读（古诗词模式）规划在 V1.1 阶段支持。

## 八、卡片导出与多主题分享体系

在 App 内，无论是单条句子、整首诗歌、还是诗集点评，均可随时生成高质感卡片导出：

1. **导出粒度**：
   * **单句卡片**：桌面风格，突出名句与作者，留白考究，支持独立句子和诗集中某篇诗的节选两个入口。
   * **整诗长图**：完整保留诗行、副标题、印章与来源信息。
   * **诗集精选合辑**：生成精选清单长图。
2. **多主题设计系统**：
   * 小组件的主题系统与导出卡片主题完全打通，保证视觉一致性。
   * 提供古典、现代、极简、报刊、日历等排版模板。
   * 支持一键保存高清图片至系统相册，或直接分享至微信/系统分享面板。

## 九、数据统计（个人读诗年轮）

区别于强调焦虑感的“打卡/排行榜”，StillPoets 的数据统计主打**“静默记录、温柔回望”**——所有阅读轨迹均保存在本地与用户私有 WebDAV 元数据中，不上传第三方服务器。顶部支持按 **本周 / 本月 / 今年 / 全部** 切换时间窗口，展示核心总览指标（累计读过诗篇数、已读完诗集数、精选诗篇 ❤️ 与独立句子数、累计批注/书评数）。

### 9.1 已读完的诗集（完读墙）
* **完读判定机制**：
  * **自动完读**：当某本诗集的全部正文篇目均被记录为已读时，自动标记为“已读完”并记录完读时间。
  * **手动校准**：支持用户手动标记“已读完”或“二刷/重读中”，避免因序言、后记、附录未翻看导致进度永远停在 98%。
* **展示形态**：
  * 以书封墙或时间轴卡片按完读时间倒序排列，展示封面、诗集名、作者、完读日期、该书内点亮的小红心 ❤️ 数量及是否已写诗集长书评。
  * 点击任意完读诗集可回看详情、查看全书精选与书评，或一键生成“完读纪念卡”。

### 9.2 读诗热力图（按诗集的某首诗粒度）
* **统计粒度**：以**“具体某本诗集中的某首诗”**为最小统计单位（而非笼统的打开 App 次数或纯阅读时长），更契合诗歌短小精炼、按篇品读的阅读习惯。
* **有效读诗判定**：进入单首诗页面停留超过设定阈值（如默认 ≥ 5 秒，或滚动至诗末 / 左滑切至下一首）即记为一次有效读诗事件，过滤快速翻目录、误触划过等噪声；同一首诗当日反复翻看按单日去重计篇数，并支持区分“初读”与“重读”。
* **视觉与交互下钻**：
  * 采用年度/季度日历热力图，依据当日读诗篇数划分色阶（如 0 首、1~2 首、3~5 首、6~10 首、10 首以上），配色随当前 App 主题（水墨/宣纸/暗黑等）自适应。
  * **点击任意日期下钻**：点击热力图上的某一天，下方展开**当日读诗明细列表**（展示当天读了哪几本诗集的哪几首诗、阅读时间、是否点亮 ❤️ 或写下批注），点击某首诗可直接跳转回整诗阅读页（若该设备尚未下载对应诗集，自动按需下载后展开）。

### 9.3 阅读时段占比（昼夜节律）
* **时段切分与可视化**：
  * 基于每次有效读诗事件的发生时间，统计用户的阅读时间分布。
  * 提供**诗意时段环图/占比条**（清晨 05:00–09:00、上午 09:00–12:00、午后 12:00–18:00、入夜 18:00–23:00、深夜 23:00–05:00），并支持切换至 **24 小时细粒度分布柱状图**。
* **轻量洞察文案**：自动生成一句克制的个人读诗节律摘要（例如：“你偏爱在入夜至深夜读诗，21:00–01:00 贡献了 46% 的读诗时刻”）。

### 9.4 作者云（诗人偏好图谱）
* **聚合维度与权重切换**：
  * 综合统计**入口 A（诗集阅读与诗篇精选 ❤️）**与**入口 B（独立句子收藏）**中出现的诗人/作者，支持用户在「按读过诗篇数」「按精选与收藏数」「综合权重」间切换。
  * 针对多人合集（如《唐诗三百首》《中国现代诗选》），优先读取**单首诗级别的作者字段**进行归属统计，避免全部算作“编者/佚名”。
* **视觉与下钻交互**：
  * 以字体大小与墨色浓淡呈现高频诗人词云（视觉贴合书卷/水墨气质，避免杂乱配色）。
  * **点击诗人下钻**：点击词云中的任意诗人（如“海子”“里尔克”“李商隐”），弹出该诗人的个人档案卡——汇总展示你读过他的多少首诗、分布在哪些诗集、收藏的精选诗篇与独立句子，并支持直接进入对应诗篇或句子列表。

### 9.5 统计卡片导出（联动分享体系）
* 复用第八章的卡片导出与主题系统，支持将「月度 / 年度读诗报告」（包含完读诗集数、读诗热力图缩略图、最常读诗时段与 TOP 诗人云）一键导出为高清纪念长图。
