## 2. 信息架构与交互红线

1. **三栏底部导航（平板转为最左侧窄导航轨）**：
   - **`书架`**：顶部保留 `StillPoets` 品牌字标、`🔍 搜索`、`+ 新增`（全部新增动作收敛至此，底部不再重复放导入/记录按钮）；次行常驻切换 **`诗集 / 散页`**。
   - **`统计`**：V1.0 展示轻量读诗总览，V1.1 扩展完读墙、热力图、时段占比与作者云。
   - **`我的`**：集中收纳 WebDAV 同步配置、旧设备退役、外观主题与自定义字体、桌面小组件设置及本地缓存管理。
2. **分组直达（不藏二级页）**：
   - 书架「我的诗集」标题右侧放轻量 `管理分组`（新建空组/重命名/排序/解散）；
   - 下方直接横向铺开分组切换条（`全部 / 现代诗 / 外国诗 / 枕边重读`），点一下即筛选对应诗集封面网格。
3. **「诗集 / 散页」双入口融合**：
   - 诗集页保留「今日重读 → 继续阅读 → 我的诗集」阅读节奏；诗节主行动为 `读完整首`，次行动为 `🔖 留作散页`（与整诗 `❤️ 精选` 严格区分）。
   - 散页页采用错位双栏纸卡瀑布流（平板扩展 3~4 列），类型筛选收敛为 `全部 / 诗歌节选 / 独立散句`，并支持按 `原书出处 / 作者` 筛选（V1.0 不按收藏筛选，仅支持手动「记一张」与阅读器划句留存；Reeden 外部导入留待后续版本）：
     - 来自诗集的「诗歌节选」携带 `(bookId, poemId, poemTitle, highlightLines)` 溯源并提供 `读完整首 ↗`；同一首诗支持多次划选不同段落生成多张散页；若原诗集被删则保留文字并自动降级为独立散句；
     - 独立散句（手动记一张及后续外部导入）无整诗上下文，不展示 `读完整首`；小组件支持「散页池」抽选，诗歌节选跳回原诗，独立散句打开单句卡片。
4. **瞬态云同步提示**：
   - 不保留常驻底部同步状态条；同步时在底栏上方浮出轻胶囊（`同步中…` → `☁ 云同步成功` / `部分同步`），成功约 2 秒后自动淡出，恢复干净常态。
5. **现代诗歌出版美学**：
   - 刊物风的页面留白、顶栏与安全区、阅读纸面、白色卡片和小组件快照共用 `#FFFFFF`。白卡以 `#E5E5E5` 细边和留白分隔，次级控件底色使用中性灰 `#F2F2F2`。
   - 面向现代诗与世界诗歌阅读，拒绝水墨、印章、山水等古风装饰；
   - 无封面诗集按 `bookId` 确定性生成抽象几何书封，与整体色彩体系浑然一体。
